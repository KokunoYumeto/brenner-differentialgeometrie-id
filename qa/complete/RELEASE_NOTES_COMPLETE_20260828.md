# Geometri Diferensial dan Manifold Mulus — Edisi Bahasa Indonesia

Version `2026.08.28-complete` is the complete reader-first Indonesian edition
of Holger Brenner's *Differentialgeometrie (Osnabrück 2023)* course architecture.
It succeeds Zenodo record `22146873` in the existing concept lineage
`22059977`; it does not create a competing concept.

The core contains all 29 lectures and all 29 corresponding worksheets in source
order. It preserves 576 source exercises and all 84 worksheet solutions that
the frozen source actually supplies. The official cumulative assessment bank
contains ten learner forms: 147 nominal template slots, 123 actual problem
occurrences, 24 explicitly excluded placeholders, and 117 source-supplied
solution occurrences. Six source-missing solution occurrences have separately
labelled original solutions and are never represented as source-supplied.

Two independently authored curricular bridges complete the selected scope: one
for Lie groups and Lie algebras, and one for de Rham cohomology and the bounded
differential-topology gateway. Each bridge contains 12 exercises and a
four-problem mastery check with hints and complete solutions, for 32 original
solution-bearing bridge items. Together with the six exam repairs, the edition
contains exactly 38 clearly provenanced original solution-bearing items.

The release is ordered for readers: the complete centered A4 PDF is first, the
reflowable semantic HTML ZIP is second, and a compact resumable source/backend
ZIP is third. The source package binds deterministic rebuild scripts, admitted
source and translation files, essential QA and rights receipts, and 6,912
stable-ID backend records. `FILE_MANIFEST.json` and `SHA256SUMS.txt` bind the
exact public bytes. Final PDF pagination is recorded by the structural and
release-preparation receipts rather than estimated here.

The semantic HTML exposes all 29 core units, ten actual-problem exam forms, both
bridges, source-supplied and original solution provenance, stable internal
anchors, responsive centered reflow, MathJax source fallback, media alternative
text, and file-specific rights. Its complete deterministic gate records 1,766
unique resolved IDs, 36 figure occurrences, 35 embedded media files, three
source-linked media files, and two independent byte-identical restages.
